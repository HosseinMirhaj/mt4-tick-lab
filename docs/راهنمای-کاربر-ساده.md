# راهنمای استفاده برای کاربران MT4 Tick Lab

## این پروژه چه کاری انجام می‌دهد؟

این پروژه از همان ترمینال MetaTrader 4 که قیمت را دریافت می‌کند، تیک‌های واقعی نماد را جمع می‌کند، آن‌ها را اعتبارسنجی می‌کند و در محیط آفلاین برای Strategy Tester فایل‌های M1/HST/FXT می‌سازد.

اصل پروژه این است: داده باید از همان بروکر، همان سرور و همان ترمینالی بیاید که قرار است رفتار آن را بررسی کنیم. داده‌ی ساختگی یا داده‌ی سرور دیگر جایگزین داده‌ی واقعی نیست.

## فرق فایل‌های MQL4

`MT4_TickCollector.mq4` یک اندیکاتور است، نه EA. آن را روی چارت زنده می‌اندازید و کنار EA معاملاتی شما کار می‌کند؛ سفارش نمی‌فرستد.

`MT4_SymbolSpecSnapshot.mq4` یک اسکریپت یک‌بارمصرف است. مشخصات قرارداد همان نماد و همان سرور را می‌خواند تا در ساخت FXT حدس نزنیم. این اسکریپت معامله نمی‌کند.

`MT4_FXT_SmokeTest.mq4` فقط EA آزمایشی Strategy Tester است. روی ترمینال زنده کاربرد ندارد و هیچ سفارش معاملاتی ارسال نمی‌کند.

فایل‌های Python برای تبدیل و اعتبارسنجی داده هستند و روی MT4 نصب نمی‌شوند.

## پیش‌نیازها

روی ویندوز به MetaTrader 4، Python 3.11 یا جدیدتر، و دسترسی PowerShell نیاز دارید. پروژه را از GitHub دریافت کنید و PowerShell را در پوشه پروژه باز کنید.

```powershell
cd C:\MT4-Tick-Lab
```

در یک سرور چند MT4، هر ترمینال باید Data Folder جدا و شناسه‌ی جدا داشته باشد. نصب Collector روی یک ترمینال، Collector ترمینال‌های دیگر را فعال نمی‌کند.

## روش ساده با اسکریپت اصلی

راحت‌ترین روش این است:

```powershell
.\mt4-tick-lab.ps1 install
```

اگر PowerShell اجرای اسکریپت را مسدود کرد:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\mt4-tick-lab.ps1 install
```

یا روی ویندوز روی فایل زیر دوبار کلیک کنید:

```text
RUN_MT4_TICK_LAB.bat
```

اسکریپت پوشه‌های MT4 را پیدا می‌کند و فایل‌های سورس Collector و Snapshot را کپی می‌کند. اسکریپت عمداً فایل EX4 را بی‌صدا جایگزین نمی‌کند؛ باید در MetaEditor آن‌ها را Compile کنید تا بدانید دقیقاً چه نسخه‌ای اجرا می‌شود.

اگر چند MT4 پیدا شد، شماره‌ی Data Folder درست را انتخاب کنید. برای نصب خودکار با مسیر مشخص:

```powershell
.\mt4-tick-lab.ps1 install -DataFolder "C:\Path\To\MT4\DataFolder"
```

## نصب و تست Collector

پس از اجرای `install`، MetaEditor را باز کنید و این دو فایل را Compile کنید:

```text
MQL4\Indicators\MT4_TickCollector.mq4
MQL4\Scripts\MT4_SymbolSpecSnapshot.mq4
```

در MT4 روی Navigator راست‌کلیک و `Refresh` بزنید. سپس `MT4_TickCollector` را روی چارت نماد هدف بیندازید. تنظیم `IncludeAccountLogin` را روی `false` نگه دارید.

قبل از اینکه چند ساعت صبر کنید، رشد فایل را کنترل کنید:

```powershell
.\mt4-tick-lab.ps1 check -DataFolder "C:\Path\To\MT4\DataFolder"
```

اسکریپت ۶۰ ثانیه صبر می‌کند. باید پیام `[PASS] CSV is growing` بگیرید. اگر فایل رشد نکرد، Collector روی چارت نیست، ترمینال قطع است، نماد تیک نمی‌گیرد، یا EX4 قدیمی اجرا می‌شود. تا وقتی این کنترل موفق نشده، جمع‌آوری طولانی را شروع نکنید.

## گرفتن مشخصات نماد

روی همان چارت و همان سرور، از `Navigator > Scripts` اسکریپت `MT4_SymbolSpecSnapshot` را یک بار اجرا کنید. خروجی در این مسیر قرار می‌گیرد:

```text
MQL4\Files\MT4TickLab\specs\symbol_spec_<SYMBOL>_<STAMP>.csv
```

این فایل را برای ساخت FXT نگه دارید. از مشخصات نماد یا سرور دیگری استفاده نکنید.

## جمع‌آوری داده

Collector فایل‌های `metadata_*.csv` و `ticks_*.csv` را داخل Data Folder می‌نویسد. برای Strategy Tester کمتر از ۱۰۰ کندل M1 کافی نیست؛ برای حاشیه‌ی اطمینان، حداقل ۲۰۰ کندل واقعی هدف بگیرید. مدت زمان به‌تنهایی معیار نیست؛ تعداد کندل واقعی را بررسی کنید.

در اجرای چند MT4، داده‌ها را از هر Data Folder جداگانه بردارید. هیچ فایل داده‌ای را در GitHub عمومی قرار ندهید.

## ساخت HST و FXT

پس از پایان جمع‌آوری، پوشه‌ای بسازید و فقط `metadata_*.csv` و `ticks_*.csv` همان نشست را داخل آن قرار دهید. سپس:

```powershell
.\mt4-tick-lab.ps1 build -InputFolder "C:\MT4-Tick-Lab\incoming\session" -OutputFolder "C:\MT4-Tick-Lab\output\session" -TesterSymbol GOLD -SkipFxt
```

این دستور Validator، Dataset، کندل‌های M1 و HST را می‌سازد. اگر نام نماد همان نام منبع است، `-TesterSymbol` را حذف کنید. اگر در فایل CSV نماد `XAUUSD` است ولی در MT4 تستر `GOLD` نام دارد، `-TesterSymbol GOLD` بگذارید.

برای ساخت FXT باید هدر مرجع FXT از همان Build و همان نماد و فایل Spec همان سرور را نیز داشته باشید:

```powershell
.\mt4-tick-lab.ps1 build `
  -InputFolder "C:\MT4-Tick-Lab\incoming\session" `
  -OutputFolder "C:\MT4-Tick-Lab\output\session" `
  -ReferenceFxt "C:\MT4-Tick-Lab\reference\XAUUSD1_0.fxt" `
  -SpecCsv "C:\MT4-Tick-Lab\reference\symbol_spec_XAUUSD.csv" `
  -TesterSymbol GOLD
```

اگر Reference یا Spec متناظر ندارید، فقط HST بسازید و از ساخت FXT با مشخصات حدسی خودداری کنید.

## تست آفلاین

HST و FXT را فقط در یک کپی آفلاین MT4 نصب کنید:

```text
Offline MT4\history\<server>\GOLD1.hst
Offline MT4\tester\history\GOLD1_0.fxt
```

ترمینال زنده را لمس نکنید. فایل FXT نباید Read-only باشد. در Strategy Tester، `MT4_FXT_SmokeTest`، نماد، M1 و `Every tick` را انتخاب کنید و تاریخ تست را با بازه‌ی واقعی داده هم‌پوشان بگذارید. کادر تاریخ MT4 ساعت نمی‌گیرد.

## معنی خطاهای رایج

`deficient data (N rate records)` یعنی MT4 کمتر از حداقل لازم کندل پیدا کرده است؛ N تعداد کندل پیداشده است.

`no history data` یعنی در تاریخ انتخاب‌شده کندلی پیدا نشده یا HST در پوشه‌ی سرور فعال نیست.

`cannot open [5]` معمولاً یعنی FXT Read-only است یا MT4 آفلاین هنوز فایل را باز نگه داشته است.

CSV فقط هدر دارد یعنی Collector روی چارت فعال نبوده، چارت تیک نگرفته، یا نسخه‌ی کامپایل‌شده‌ی درست نصب نشده است.

## قواعد امنیتی

هیچ رمز، توکن، IP خصوصی، شماره حساب، CSV، HST، FXT، لاگ یا EX4 را در گروه عمومی یا GitHub عمومی ارسال نکنید. مقدار `IncludeAccountLogin=false` را نگه دارید. HST و FXT را فقط روی کپی آفلاین بسازید و نصب کنید.
